# Fonts

Self-hosted so the demo runs offline and the CSP stays `default-src 'self'`.

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| `archivo-latin-1.woff2` | Archivo (variable, latin) | 400–700 | Google Fonts |
| `newsreader-latin-2.woff2` | Newsreader (variable, latin) | 400–600 | Google Fonts |

Both families are licensed under the SIL Open Font License 1.1; the license
texts sit beside the files (`OFL-Archivo.txt`, `OFL-Newsreader.txt`). The
woff2 subsets were fetched from `fonts.googleapis.com` in October 2026 and are
declared with `@font-face` at the top of `style.css`.
